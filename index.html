advanced-freeze-panes-table

Premium freeze panes — adaptive mode, right-side freeze, boundary-stick panes, themes, bold panes, header arrows, and image/text cells. Build first (npm run build), then open this file.

1. Adaptive mode — responsive table vs frozen table

Small data with no freeze renders as a plain responsive table. Adding a freeze config on the same data switches to the advanced frozen table automatically.

mode: table

2. Auto threshold — big data switches automatically

Currently 10 rows. Load 200 rows and the table switches to the advanced frozen table on its own.

mode: table

3. Financial grid — freeze top + left + right, themes, arrows

Freeze the header, the ticker column, and the trailing signal column; dark theme, compact density, header arrows, bold header, and bold frozen-left pane.

4. Excel-style freeze panes at a cell

freezeAt: { row: 2, col: 3 } freezes every row above and every column to the left of that cell.

5. Boundary-stick panes

Frozen cells scroll normally until they touch their pane edge (top, left, or right) and only then stick — the Excel feel.

6. Pinned cells + programmatic scroll

7. Image + text cells

Sparkline images with object-fit, right-aligned numeric text, centered badges. Cycle the default image fit.

8. Live updates

update() re-renders without rebuilding the controller.
