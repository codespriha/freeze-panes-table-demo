# advanced-freeze-panes-table — live demo

Public demo site for the premium [`advanced-freeze-panes-table`](https://www.npmjs.com/package/advanced-freeze-panes-table)
package. This repo contains **only the built demo** (compiled `dist/` + `index.html`) —
the premium source code stays in its private repository.

## View

Open https://codespriha.github.io/freeze-panes-table-demo/

## Updating

The demo is generated by `scripts/sync-demo.sh` inside the (private) premium
repo — build, copy the demo + `dist/`, commit, and push here. Never edit files
in this repo by hand.

## Contents

- `index.html` — the demo, showcases adaptive mode, right-side freeze,
  boundary-stick panes, themes, bold panes, header arrows, and image/text cells
- `dist/` — compiled ESM build of `advanced-freeze-panes-table`
